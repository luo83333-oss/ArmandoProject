# 平台规则与商家入驻协议（草案）

> **说明**：本文档为 Phase 0 草稿，正式对外前需法务审核签字。

## 一、入驻条件

1. 具备有效营业执照及合法经营资质。
2. 提交真实联系人、手机号、营业执照扫描件。
3. 平台在 3–5 个工作日内完成审核。

## 二、商品与经营规范

1. 禁止假冒伪劣、侵权、违禁品。
2. 商品信息须真实准确；违规商品可被下架并扣分。
3. 商家须按订单约定发货，填写有效物流单号。

## 三、费用与结算

1. 平台按订单实付金额收取 **5%** 技术服务费（抽佣），详见订单快照。
2. 结算周期与提现规则在 Phase 2 支付上线后另行约定。

## 四、违规处理

| 行为 | 处理 |
|------|------|
| 虚假交易、刷单 | 降权、冻结店铺、清退 |
| 售假侵权 | 下架商品、扣分、永久封禁 |
| 无故不发货 | 限制上新、暂停营业 |

店铺权重算法将纳入销量、评价、违规扣分（Phase 2）。

## 五、免责声明（摘要）

平台作为信息服务方，商家对其商品质量与售后服务承担首要责任。
