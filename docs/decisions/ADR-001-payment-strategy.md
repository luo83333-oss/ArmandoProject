# ADR-001：支付接入策略

**状态**：已采纳 | **日期**：2026-06-05

## 背景

微信支付/支付宝需企业资质与商户号，审核周期不确定。

## 决策

| 阶段 | 策略 |
|------|------|
| Phase 1（W4） | 使用**模拟支付**：用户点击支付后，后端直接将订单置为「已支付」，写入 `payment_record.channel=mock` |
| Phase 2（W7） | 在商户号就绪后接入微信 Native/JSAPI、支付宝；保留 mock 供测试环境 |
| 商户号未获批 | 延续 mock，不阻塞 MVP 验收 |

## 后果

- Phase 1 可完整演示交易闭环
- Phase 2 需单独处理回调幂等、对账
- NL2-88（申请商户号）仍为外部依赖，但不阻塞开发
